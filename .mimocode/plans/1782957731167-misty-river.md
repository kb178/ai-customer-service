# 后台管理系统实现计划

## 概述

为 AI 智能客服系统构建完整的后台管理系统，包含 Vue 3 + Element Plus 前端和 Spring Boot 后端管理 API。覆盖课程管理、校区管理、预约管理、客户管理、对话记录、留言管理、FAQ管理、系统提示词管理、统计面板共 9 个模块。

---

## 一、后端基础设施

### 1.1 统一响应封装

新建 `src/main/java/com/aicustomer/controller/admin/` 包，新增统一响应类：

```java
// AdminResponse.java — 管理后台统一响应格式
@Data @AllArgsConstructor
public class AdminResponse<T> {
    private int code;       // 200=成功, 400=参数错误, 401=未登录, 500=服务异常
    private String message;
    private T data;

    public static <T> AdminResponse<T> ok(T data) { ... }
    public static <T> AdminResponse<T> error(int code, String msg) { ... }
}
```

分页响应：
```java
// PageResult.java
@Data @AllArgsConstructor
public class PageResult<T> {
    private List<T> records;
    private long total;
    private int page;
    private int size;
}
```

### 1.2 简单登录认证

- 不引入 JWT，使用 Spring Interceptor + Session
- 新建 `AdminInterceptor`：拦截 `/api/admin/**`，检查 session 中是否有 `adminUser` 标记
- 新建 `AdminLoginController`：`POST /api/auth/login`（用户名密码验证，硬编码 admin/123456）
- 在 `WebMvcConfigurer` 中注册拦截器，排除 `/api/auth/login`

### 1.3 对话记录持久化

当前对话存储在 Redis（RedisChatMemory），30 分钟过期，管理后台无法查询历史。

- 新建数据库表 `conversation_log`（id, session_id, role, content, create_time）
- 新建实体 `ConversationLog`、Mapper、Service
- 在 `FunctionCallingChatServiceImpl.chat()` 中，每次 AI 回复后将用户消息和 AI 回复写入 `conversation_log` 表

```sql
CREATE TABLE conversation_log (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    session_id VARCHAR(64) NOT NULL COMMENT '会话ID',
    customer_phone VARCHAR(20) COMMENT '客户手机号',
    role VARCHAR(20) NOT NULL COMMENT 'user/assistant',
    content TEXT NOT NULL COMMENT '消息内容',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_session_id (session_id),
    INDEX idx_customer_phone (customer_phone),
    INDEX idx_create_time (create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='对话记录表';
```

CREATE TABLE faq (

    deleted TINYINT DEFAULT 0
